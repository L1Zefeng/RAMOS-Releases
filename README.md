# RAMOS

可靠性分析与维修优化系统  
Reliability Analysis and Maintenance Optimization System

适用于 Windows 10/11（64 位）。计算在本机完成，无需安装 Python 或 Conda，使用前需要激活码。

## 开始使用

1. 下载 [在线安装器 RAMOS-Setup.exe](https://github.com/L1Zefeng/RAMOS-Releases/releases/download/v2026.10.07.5/RAMOS-Setup.exe)，双击打开。
2. 选择安装位置，点击“安装”。安装器会从 GitHub 下载最新版本，可勾选创建桌面快捷方式。
3. 首次打开时输入激活码。以后每次打开会联网验证，不必重复输入。

安装器很小，但首次仍需下载约 989 MB 的程序文件，速度取决于访问 GitHub 的网络情况。安装器链接固定，下载的软件版本会随发布更新。

也可以在 [下载页面](https://github.com/L1Zefeng/RAMOS-Releases/releases/latest) 下载 `RAMOS-Windows-x64.zip`，完整解压后运行 `RAMOS.exe`。不要只复制这个 EXE，也不要在压缩包内直接运行。具体操作见包内的 `RAMOS使用手册.docx`。

安装器不会覆盖已有的 RAMOS 文件夹；已有版本请从软件内更新。当前安装器尚无 Windows 代码签名，系统可能显示未知发布者提示，请核对下载来源。

## 软件更新

打开软件后会自动检查新版本，有更新时会显示提示。点击“下载更新”并确认后开始下载，不影响正在进行的计算。

下载完成后，保存正在编辑的模型，在右下角系统托盘中右键 RAMOS 图标，选择“退出程序”。下次打开时会安装更新。**只关闭网页不会退出程序。**

也可以在右上角“关于 RAMOS”中手动检查更新。更新会保留设置、授权和计算记录；未改动的素材不重复下载。GitHub 暂时连不上时，仍可使用已通过授权验证的当前版本。

在线更新从 **2026.10.07.5** 开始支持。更早的版本需要先手动换用一次完整包。下载页面中的 JSON 和 SIG 文件由更新器使用，不用单独下载。

## 其他

- 关闭软件请使用系统托盘菜单，避免后台仍在运行。
- 吉祥物默认关闭，需要时在“关于 RAMOS”中开启。
- 反馈问题时请附上版本号和报错截图，不要公开激活码或私人数据。

本仓库用于发布程序和更新，不包含源码。
