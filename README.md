# RAMOS

可靠性分析与维修优化系统  
Reliability Analysis and Maintenance Optimization System

当前版本：**0.9.0 内测版**，适用于 64 位 Windows 10/11。

## 下载

[在线安装器](https://github.com/L1Zefeng/RAMOS-Releases/releases/latest/download/RAMOS-Setup.exe) · [完整安装包](https://github.com/L1Zefeng/RAMOS-Releases/releases/latest/download/RAMOS-Windows-x64.zip)

运行安装器，选择目录后安装。也可完整解压 ZIP，运行其中的 `RAMOS.exe`。首次使用需要激活码，每次打开需联网验证。无需另装 Python。

详细操作见包内《RAMOS 使用手册》。程序尚无 Windows 代码签名，下载时请核对来源。

## 更新

在“关于 RAMOS”中下载更新，保存模型并从系统托盘退出，再次打开即可安装。关闭网页不会退出程序。

内测期间只保留最新发布。修复问题递增修订号（0.9.1），新增功能递增次版本号（0.10.0）；完成内测后再发布 1.0.0。

本仓库仅发布安装包和更新文件，不包含源码。反馈问题时请附版本号、操作步骤及错误截图，不要公开激活码或私人数据。
